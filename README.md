# Panel de mercado

- `modelo.py`: calcula el régimen de mercado (Calma / Tensión / Pánico) y la volatilidad esperada de ~46 acciones del Nasdaq, y escribe `docs/datos.json`.
- `.github/workflows/actualizar.yml`: lo ejecuta solo de lunes a viernes a las 6:37 a. m. (hora de Lima).
- `docs/`: la página web (GitHub Pages): `index.html` (régimen, volatilidad y calculadora), `mapa.html` (mapa Nasdaq-100) y `cripto.html` (mapa cripto).

Herramienta de estudio; no es asesoría de inversión.
